# aditya-prakash.me

Source for my personal website, [aditya-prakash.me](https://aditya-prakash.me). It is built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme.

## Where things live

| What                  | File                                                                            |
| --------------------- | ------------------------------------------------------------------------------- |
| Bio and profile photo | `_pages/about.md`, `assets/img/prof_pic.jpg`                                    |
| News                  | `_news/` (one Markdown file per item)                                           |
| Publications          | `_bibliography/papers.bib` (`selected = {true}` shows a paper on the home page) |
| CV page               | `_data/cv.yml`, with the PDF at `assets/pdf/Aditya_Prakash_CV.pdf`              |
| Social links          | `_data/socials.yml`                                                             |
| Site settings         | `_config.yml`                                                                   |

Pushing to `main` runs the **Deploy site** workflow, which builds the site and publishes it to the `gh-pages` branch. al-folio's own documentation is in [`docs/`](docs/).

The site I used before 2026 is archived in `OldWebsite/`.
